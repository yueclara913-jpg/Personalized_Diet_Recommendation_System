# 健康档案与营养目标计算

本模块为一般健康成年人提供可解释的参考估算，不构成疾病诊断、治疗方案或个体化医疗处方。当前项目没有普通用户身份认证，因此本阶段没有新增健康档案 HTTP CRUD 接口或页面。档案仅能由可信本地代码通过显式数据库路径和不可猜测的本地 `profile_id` 使用；建立用户认证、对象级授权和隐私策略前，不应公开这些仓储函数。

## 数据隔离

健康档案使用独立 SQLite 数据库（`application_id=0x48505246`、`user_version=1`），不写入管理员认证库、USDA 暂存库或正式营养数据库。初始化要求全新路径并拒绝覆盖；数据库打开时校验版本、完整结构和完整性。写入采用参数化 SQL、事务和并发更新时间检查。档案不收集姓名、手机号、身份证号；`sex_for_equation` 只表示 Mifflin–St Jeor 公式参数选项，不代表用户的性别身份。

```sh
python scripts/init_health_profiles.py --database /explicit/private/health-profiles.sqlite
```

## 公式与边界

- BMI：`kg / m²`，分类采用代码中显式配置的 WHO 成人参考阈值，仅为筛查描述。
- BMR：Mifflin–St Jeor 成人估算，男性参数偏移 `+5`、女性参数偏移 `-161`。
- TDEE：BMR 乘活动系数 `1.20 / 1.375 / 1.55 / 1.725 / 1.90`。
- 目标调整：维持 `0`、控制体重 `-300 kcal/day`、增重 `+250 kcal/day`；配置硬边界为 `[-500, 500]`，偏离 TDEE 超过 20% 时要求人工专业评估。
- 默认宏量比例：蛋白质 25%、脂肪 30%、碳水 45%，分别以 4、9、4 kcal/g 换算。该约定只用于目标估算，不反向修改食品数据库热量。

支持年龄为 18～100 岁、身高 100～250 cm、体重 30～350 kg。孕期、哺乳期及其他特殊评估状态拒绝自动计算 BMR/TDEE/目标。钠、纤维和糖没有在缺乏进一步条件时生成目标。

## 营养缺口

缺口服务支持能量、蛋白质、脂肪和碳水。字段缺失或 `None` 表示摄入未知，和真实零摄入严格区分；超过目标时保留负差值、`exceeded` 及 `excess`。结果只描述算术差异，不解释为疾病风险。本模块不读取 USDA 暂存食品，也不改变现有推荐数据源。
